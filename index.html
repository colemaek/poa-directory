Poa directory

A Poa is a small personal site made of Markdown files. No accounts, no feeds, no algorithm: just people writing, and listing the other Poas they read.

These are the Poas whose owners asked to be listed. Pick one and start reading. Every Poa links to the ones its owner reads, so you can hop from there.

How to add your Poa

You need a free GitHub account. Sign in first, then:

  1. Open the list for editing: poas.md on GitHub.
  2. GitHub says "You need to fork this repository to propose changes." That's expected: click the green Fork this repository button. It makes your own copy of the list, which is how you suggest a change.
  3. Go to the very end of the list and add a new line with a dash, a space and your address, like - yourname.codeberg.page/poa. Change nothing else.
  4. Click the green Commit changes… button at the top right, then Propose changes in the box that opens.
  5. On the Comparing changes page, click Create pull request, then Create pull request again.

An automatic check opens your Poa and shows a green tick or a red cross on your pull request. Once it's green, a maintainer adds you. More details, and what the check looks for, are in the README.
